# BookHaven - WEB Technologies 1 Final Project

Demo front-end website meeting the Final Project requirements.

## Features
- Semantic HTML5 structure
- Responsive layout (Bootstrap 5 + custom CSS)
- Light / Dark mode with localStorage persistence
- User Sign Up / Log In / Profile / Log Out (localStorage, JSON)
- Favorites system with counter and total price calculation
- Form validation with inline error messages
- Search and category filter
- jQuery effects (fade, slide, hover animations)
- Accessible navigation and focus states

## Pages
- index.html (Home)
- books.html (Catalog)
- favorites.html
- about.html
- contact.html
- login.html / signup.html / profile.html

## How to run
Open index.html in a browser or deploy the folder to GitHub Pages.

## Note
This is a pure front-end demo. No backend. Do not use real passwords.
