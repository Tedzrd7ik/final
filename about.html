About BookHaven

BookHaven is a demonstration website built for the WEB Technologies 1 Final Project. It showcases modern front-end practices without any backend.

Visitors can browse a curated catalog of books, save favorites that persist in the browser, create a demo account, and switch between light and dark modes. Everything is stored locally using the Web Storage API.

The project emphasizes semantic HTML, accessible navigation, responsive layouts with Flexbox and Bootstrap grid, custom CSS variables for theming, form validation, and interactive JavaScript features powered by data arrays.

Project Goals

  • Fully responsive across devices
  • Persistent light / dark theme
  • User accounts & favorites via localStorage
  • Client-side form validation
  • jQuery animations & effects
  • Clean, accessible interface
